# Online Food Ordering System

## Project Description
Online Food Ordering System is a web-based application developed using HTML, CSS and JavaScript.

This website allows users to view food items, search for foods, select categories, add food items to the cart and place orders easily.

## Technologies Used
- HTML
- CSS
- JavaScript

## Main Modules
- Home
- Food Menu
- Search
- Food Categories
- Shopping Cart
- Checkout
- Admin Portal

## Features
- Display food items
- Search food items
- Filter food by categories
- Add food items to cart
- View cart items
- Calculate total price
- Place orders
- Cash on Delivery
- UPI Payment option
- Admin page for managing the system

## Project Files
- index.html
- script.js
- style.css

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the file using a browser.
5. For admin page, open `admin.html`.
